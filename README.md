## 🎯 핵심 특징

1. **2024~2026 최신 사법제도 및 법령 완벽 반영**
   - **주택임대차보호법 제3조의3 제3항 개정 (2023. 7. 19. 시행)**: 임대인 송달 전 임차권등기 촉탁 제도
   - **소송촉진 등에 관한 특례법 제3조 제1항**: 소장 부본 송달 다음 날부터 **연 12% 지연손해금** 기산
   - **전자소송 인지액 10% 자동 할인** 및 **1회 송달료 5,640원 (2026. 7. 1. 기준)** 반영
2. **AI 협업형 3단계 워크플로우 (Human-in-the-Loop)**
   - `[1단계: AI 프롬프트 복사/생성]` → `[2단계: 당사자 5대 팩트체크]` → `[3단계: 전자소송 사이트 제출]`
3. **판결 후 실제 돈 받아내기 (추심 & 소송비용 회수)**
   - 5대 시중은행(KB·신한·하나·우리·NH) 및 인터넷전문은행(카카오·토스·케이) 제3채무자 법인 정보 수록
   - 채권압류 및 추심명령 신청서 작성법
   - 소송비용액확정 신청을 통해 내가 쓴 인지대·송달료 전액 임대인에게 받아내는 법
4. **4대 리얼 케이스 스터디 수록**
   - 깡통전세/임대인 잠적 공시송달 및 강제경매 배당
   - 계약 기간 중 매매로 임대인 변경(지위 승계) 및 화해권고결정
   - 묵시적 갱신 해지 분쟁(3개월 효력) 및 자진 입금 종결
   - 원상복구 트집 일부 미반환 통장 압류 추심

## 🚀 GitHub에 업로드하는 방법

### 방법 1. 웹 브라우저로 업로드 (가장 쉬운 방법)
1. GitHub([github.com](https://github.com))에 로그인 후 우측 상단 `+` 버튼 → **[New repository]** 클릭
2. Repository name 입력 (예: `lease-deposit-lawsuit-guide`) → **Public** 또는 **Private** 선택 → **[Create repository]** 클릭
3. 생성된 저장소 페이지에서 **"uploading an existing file"** 링크 클릭
4. 본 압축 파일(`lease_lawsuit_ebook_bundle.zip`)을 해제한 파일들을 드래그 앤 드롭으로 업로드 후 **[Commit changes]** 클릭!

### 방법 2. Git CLI 터미널 명령어로 업로드
```bash
git init
git add .
git commit -m "feat: Initial commit - Lease deposit lawsuit e-book complete guide"
git branch -M main
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```
